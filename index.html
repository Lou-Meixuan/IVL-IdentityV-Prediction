What this is

About the Project

IVL (Identity V League) is the premier professional esports league for Identity V. Official match results are published as image posts on Bilibili — there is no structured data source.

This project automates the collection of match results, extracts key information from images, and builds a clean CSV dataset suitable for analysis and prediction modelling.

🕷️

Automated Scraping

Collects match posts from Bilibili using Playwright browser automation

🖼️

Image Recognition

Identifies MVP players from in-game UI images using CLIP embeddings and KMeans clustering

📊

Structured Dataset

Outputs clean CSV files split by season, with match scores, teams, winners and MVP

How it works

Pipeline

1

Scrape Bilibili

Run data_collection.py to scrape match posts, parse scores and teams from post text, and download scoreboard + MVP images for each match.

2

Cluster MVP Images

Run clip_label.py --build to encode all unlabeled MVP images with CLIP (ViT-B/32), reduce dimensions with PCA, and group them into clusters with KMeans.

3

Review & Correct

Open cluster_sheet_clip.png to see the clusters visually. Fix any wrong player names in cluster_labels_clip.csv. Typically ~40 corrections for 200 images.

4

Apply Labels & Export

Run clip_label.py --apply --confirm to rename image files and write correct MVP names into the final CSV output.

项目简介

这是什么

IVL（第五人格联赛）是第五人格最高级别的职业电竞赛事。赛果以图片动态的形式发布在 Bilibili 上，没有任何结构化的数据来源。

本项目自动化收集比赛结果，从图片中提取关键信息，构建适合分析和预测建模的干净 CSV 数据集。

🕷️

自动化爬取

使用 Playwright 浏览器自动化从 Bilibili 收集赛果动态

🖼️

图像识别

使用 CLIP embedding + KMeans 聚类从游戏 UI 图片中识别 MVP 选手

📊

结构化数据集

输出按赛季分类的 CSV 文件，包含比分、队伍、胜者和 MVP 信息

运行流程

工作流程

1

爬取 Bilibili

运行 data_collection.py，抓取赛果动态，从文字中解析比分和队伍，下载每场比赛的比分图和 MVP 图。

2

聚类 MVP 图片

运行 clip_label.py --build，用 CLIP（ViT-B/32）对所有未标注的 MVP 图片做 embedding，PCA 降维后用 KMeans 聚类。

3

人工校正

打开 cluster_sheet_clip.png 查看聚类可视化，修正 cluster_labels_clip.csv 中的错误名字。约 200 张图片只需修改约 40 处。

4

应用标签并导出

运行 clip_label.py --apply --confirm，重命名图片文件并将正确的 MVP 名字写入最终 CSV。
