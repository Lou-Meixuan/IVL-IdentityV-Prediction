Guide

How to Use

Step-by-step instructions for setting up the environment and running the full pipeline.

0

Prerequisites

Make sure you have the following installed before running anything.

🐍

Python 3.10+

Recommended: use a conda environment. conda create -n ivl python=3.10

📦

Python packages

python -m pip install -r requirements.txt

🔤

Tesseract OCR

macOS: brew install tesseract

🌐

Playwright browser

python -m playwright install chromium

1

Scrape & Download

Run data_collection.py to scrape match posts from Bilibili, parse scores and team names, and download scoreboard + MVP images for each match.

terminal
python data_collection.py

This will open a Chromium browser window and scroll through the IVL Bilibili account automatically. Do not close it.

When done, you will have:

result_images/
  └── 2025IVL_Autumn_Finals/
      └── DOU5_vs_FPX.ZQ_1145xxx/
          ├── score_3-1.png
          └── mvp.png

csv_output/
  └── 2025IVL_Autumn_Finals.csv  (mvp column empty)
Note: The mvp column in the CSV will be empty at this stage. It gets filled in Step 3.
2

Cluster MVP Images

Run clip_label.py --build to encode all unlabeled mvp.png images with CLIP, then group them into clusters. Already-labeled images are automatically skipped.

terminal
python clip_label.py --build

This generates three output files:

✓ cluster_sheet_clip.png   ← visual grid of clusters
✓ cluster_labels_clip.csv  ← pre-filled with OCR suggestions
✓ cluster_mapping_clip.json ← internal mapping
Note: The CLIP model (~600MB) will be downloaded automatically on first run from HuggingFace. This only happens once.
3

Review & Correct

Open cluster_sheet_clip.png to see which images belong to each cluster. Then open cluster_labels_clip.csv and fix any wrong player names in the player_name column.

cluster_id  | n_images | player_name
──────────────────────────────────
0           | 8        | ACT_zz9     ← correct
1           | 6        | DOU5_mhxm  ← correct
2           | 5        | WBGNIe     ← fix to WBG_NIe
Tip: If the same player appears in two clusters, give both rows the same name — they will be merged when you apply.

Preview what will be renamed before committing:

terminal
python clip_label.py --apply
4

Apply & Export

Once the labels look correct, run with --confirm to rename all image files and write the MVP names back into the CSV.

terminal
python clip_label.py --apply --confirm

After this, your dataset is complete:

csv_output/
  └── 2025IVL_Autumn_Finals.csv

match_id         | team_a | team_b | winner | mvp
─────────────────────────────────────────────
1103477862...  | TE     | GG     | GG     | GG_xawm
1103539022...  | Gr     | MRC    | MRC    | MRC_Bailu
+

Adding New Data Later

When new matches are available (e.g. next season), just repeat the same steps. Already-labeled images are automatically skipped in Step 2 — only the new mvp.png files will be clustered.

New seasons get their own CSV file automatically (e.g. 2026IVL_Autumn_Finals.csv). Existing CSVs are not affected.

使用指南

如何使用

从环境配置到完整运行流程的逐步说明。

0

环境准备

运行前请确保以下依赖已安装。

🐍

Python 3.10+

推荐使用 conda 环境：conda create -n ivl python=3.10

📦

Python 依赖包

python -m pip install -r requirements.txt

🔤

Tesseract OCR

macOS：brew install tesseract

🌐

Playwright 浏览器

python -m playwright install chromium

1

爬取并下载数据

运行 data_collection.py，从 Bilibili 爬取赛果动态，解析比分和队伍名称，并下载每场比赛的比分图和 MVP 图。

终端
python data_collection.py

程序会自动打开 Chromium 浏览器并滚动 IVL 官方 Bilibili 账号页面，请勿关闭窗口。

运行完成后，会生成以下文件：

result_images/
  └── 2025IVL_Autumn_Finals/
      └── DOU5_vs_FPX.ZQ_1145xxx/
          ├── score_3-1.png
          └── mvp.png

csv_output/
  └── 2025IVL_Autumn_Finals.csv  （mvp 列为空）
注意：此阶段 CSV 的 mvp 列为空，将在第 3 步填充。
2

聚类 MVP 图片

运行 clip_label.py --build，用 CLIP 对所有未标注的 mvp.png 图片做 embedding 并聚类。已标注的图片会自动跳过。

终端
python clip_label.py --build

生成三个输出文件：

✓ cluster_sheet_clip.png   ← 聚类可视化图
✓ cluster_labels_clip.csv  ← OCR 预填的名字建议
✓ cluster_mapping_clip.json ← 内部映射文件
注意：首次运行会从 HuggingFace 自动下载 CLIP 模型（约 600MB），之后不再重复下载。
3

人工校正

打开 cluster_sheet_clip.png 查看每个 cluster 对应的图片，再打开 cluster_labels_clip.csv，在 player_name 列修正错误的选手名。

cluster_id  | n_images | player_name
──────────────────────────────────
0           | 8        | ACT_zz9     ← 正确
1           | 6        | DOU5_mhxm  ← 正确
2           | 5        | WBGNIe     ← 改为 WBG_NIe
提示：如果同一个选手出现在两个 cluster 里，给两行填写相同的名字即可，apply 时会自动合并。

确认前可以先预览重命名结果：

终端
python clip_label.py --apply
4

应用标签并导出

确认标签无误后，加上 --confirm 参数正式重命名图片文件，并将 MVP 名字写回 CSV。

终端
python clip_label.py --apply --confirm

完成后，数据集即告完整：

csv_output/
  └── 2025IVL_Autumn_Finals.csv

match_id         | team_a | team_b | winner | mvp
─────────────────────────────────────────────
1103477862...  | TE     | GG     | GG     | GG_xawm
1103539022...  | Gr     | MRC    | MRC    | MRC_Bailu
+

后续添加新数据

有新赛季数据时，重复相同步骤即可。第 2 步会自动跳过已标注的图片，只对新的 mvp.png 聚类。

新赛季会自动生成独立的 CSV 文件（如 2026IVL_Autumn_Finals.csv），不会影响已有数据。
