IVL Match Prediction

A structured dataset of Identity V League match results, built for machine learning and statistical analysis.

第五人格职业联赛（IVL）赛果数据集，为机器学习与统计分析而构建。

What's included

数据集内容

🏆

Match Results

赛果记录

Team A vs B, final score, per-game breakdown, winner — for every IVL match.

每场比赛的队伍、比分、单局细节与胜者。

🌟

MVP Labels

MVP 标注

Best Deduction player per match, identified via OCR grouping and human correction.

每场最佳演绎玩家，通过 OCR 分组与人工校正标注。

📅

Multi-Season

多赛季覆盖

Regular season and Finals data, split into per-season CSV files.

常规赛与总决赛数据，按赛季分文件输出。

🔄

Extensible

易于扩展

Add new seasons by scraping and re-running the pipeline — existing labels untouched.

新赛季只需重新抓取并运行，已有标注不受影响。

How it works

工作流程

1

Scrape Bilibili

抓取 B 站数据

Run data_collection.py to scroll the IVL official account, download scoreboard and MVP images, and output raw CSVs.

运行 data_collection.py，抓取 IVL 官方账号动态，下载比分与 MVP 图片，输出 CSV。

2

OCR Grouping

OCR 分组

Run clip_label.py --build to crop each MVP image's name tag, OCR the text, and group images by player name.

运行 clip_label.py --build，截取 name tag，OCR 识别文字，按选手名分组。

3

Review & Correct

人工校正

Check the contact sheet, fix any OCR mistakes in cluster_labels_clip_YEAR.csv.

对照 contact sheet，在 CSV 里修正 OCR 错误。

4

Apply & Export

写回数据

Run clip_label.py --apply --confirm to rename image files and write MVP names back into the season CSVs.

运行 clip_label.py --apply --confirm，重命名图片并将 MVP 名字写回赛季 CSV。
