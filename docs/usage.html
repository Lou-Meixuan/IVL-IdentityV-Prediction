How to Use

使用说明

Follow these steps to build and update the IVL match prediction dataset.

按照以下步骤构建并更新 IVL 赛果数据集。

1

Prerequisites

环境准备

Install Python dependencies and Tesseract OCR.

安装 Python 依赖和 Tesseract OCR。

pip install -r requirements.txt
# also install Tesseract: https://github.com/UB-Mannheim/tesseract/wiki
# install Playwright browsers:
playwright install chromium
2

Scrape match data

抓取赛果数据

Set TARGET_YEAR at the top of data_collection.py, then run it. A browser window will open and auto-scroll the IVL Bilibili account.

在 data_collection.py 顶部设置 TARGET_YEAR，然后运行。浏览器会自动打开并滚动 B 站 IVL 官方账号。

python data_collection.py

Outputs: images in result_images/, raw CSVs in csv_output/ (one per season).

输出：图片保存在 result_images/，CSV 保存在 csv_output/（每个赛季一个文件）。

3

Build OCR groups

OCR 分组

Crop each MVP image's name tag, run OCR, and group by player name.

截取每张 MVP 图的 name tag，运行 OCR，按选手名分组。

python clip_label.py --build --year 2025

Outputs in cluster_output/: a contact sheet PNG and a labels CSV. Each row in the CSV is one OCR group.

输出保存在 cluster_output/：一张 contact sheet 和一个标签 CSV，每行对应一个 OCR 分组。

4

Review & correct

检查与校正

Open cluster_output/cluster_sheet_clip_2025.png to see the contact sheet. Open cluster_output/cluster_labels_clip_2025.csv and fix any wrong player names in the player_name column.

打开 cluster_output/cluster_sheet_clip_2025.png 查看分组效果。打开对应 CSV，修正 player_name 列中识别错误的选手名。

OCR is usually correct. Only fix the rows where the name is wrong or missing.
OCR 大部分情况准确，只需修正错误或缺失的行。
5

Apply & export

写回并导出

Preview first (no files changed):

先预览（不实际修改）：

python clip_label.py --apply --year 2025

Then confirm to rename image files and write MVP names into the CSVs:

确认无误后执行，重命名图片并将 MVP 名字写回 CSV：

python clip_label.py --apply --year 2025 --confirm
+

Adding new season data

新赛季数据

Change TARGET_YEAR to the new year, re-run data_collection.py, then run clip_label.py --build --year 2026. Previously labeled years are completely unaffected.

将 TARGET_YEAR 改为新年份，重新运行 data_collection.py，然后运行 clip_label.py --build --year 2026。已有年份的标注完全不受影响。

If you need to redo labeling for a year: python clip_label.py --reset --year 2025 — this renames all mvp_*.png back to mvp.png and clears the mvp column in the CSVs.
如需重新标注某年：运行 python clip_label.py --reset --year 2025，会将所有 mvp_*.png 改回 mvp.png 并清空 CSV 中的 mvp 列。
