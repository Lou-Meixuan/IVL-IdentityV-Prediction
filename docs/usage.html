How to Use

使用说明

Follow these steps to build and update the IVL match prediction dataset.

按照以下步骤构建并更新 IVL 赛果数据集。

1

Prerequisites

环境准备

Install Python dependencies and Tesseract OCR.

安装 Python 依赖和 Tesseract OCR。

pip install -r requirements.txt
# install Tesseract: https://github.com/UB-Mannheim/tesseract/wiki
playwright install chromium
2

Scrape match data

抓取赛果数据

Set TARGET_YEAR at the top of data_collection.py, then run it.

在 data_collection.py 顶部设置 TARGET_YEAR，然后运行。

python data_collection.py

Outputs: images in result_images/, CSVs in csv_output/ (one per season).

输出：图片在 result_images/，CSV 在 csv_output/（每个赛季一个文件）。

3

Build OCR groups

OCR 分组

Crop each MVP image's name tag, run OCR, and group by player name.

截取每张 MVP 图的 name tag，运行 OCR，按选手名分组。

python clip_label.py --build --year 2025

Outputs in cluster_output/: a contact sheet PNG and a labels CSV.

输出保存在 cluster_output/：contact sheet 和标签 CSV。

4

Review & correct

检查与校正

Open cluster_output/cluster_sheet_clip_2025.png, then fix any wrong names in cluster_output/cluster_labels_clip_2025.csv.

打开 contact sheet，在 CSV 里修正识别错误的选手名。

OCR is usually correct. Only fix the rows where the name is wrong or missing.
OCR 大部分情况准确，只需修正错误或缺失的行。
5

Apply & export

写回并导出

Preview first:

先预览：

python clip_label.py --apply --year 2025

Then confirm:

确认后执行：

python clip_label.py --apply --year 2025 --confirm
+

Adding new season data

新赛季数据

Change TARGET_YEAR, re-run data_collection.py, then run clip_label.py --build --year 2026. Previously labeled years are unaffected.

修改 TARGET_YEAR，重新运行 data_collection.py，再运行 clip_label.py --build --year 2026。已有年份标注不受影响。

To redo labeling for a year: python clip_label.py --reset --year 2025
如需重做某年标注：python clip_label.py --reset --year 2025
