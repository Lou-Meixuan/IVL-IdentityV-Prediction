Design Document

设计文档

Technical architecture and design decisions for the IVL match prediction dataset pipeline.

IVL 赛果数据集 Pipeline 的技术架构与设计决策说明。

Overview

概述

The pipeline has two stages: data collection (scraping) and MVP labeling. They are decoupled — scraping outputs unlabeled CSVs and raw images; labeling reads those images and writes MVP names back into the CSVs.

Pipeline 分两个阶段：数据采集（爬取）和 MVP 标注。两者解耦——爬取阶段输出未标注的 CSV 和原始图片，标注阶段读取图片后将 MVP 名字写回 CSV。

Components

模块说明

data_collection.py

Playwright-based scraper. Scrolls the IVL Bilibili space page, intercepts the opus/feed/space API, filters posts by season keywords and TARGET_YEAR, then navigates to each post to extract image URLs. Downloads two images per match (scoreboard + MVP) into result_images/SEASON/TEAM_vs_TEAM_ID/. Outputs one CSV per season into csv_output/.

基于 Playwright 的爬虫。滚动 B 站 IVL 主页，拦截 opus/feed/space API，按赛季关键词和 TARGET_YEAR 过滤，访问每篇动态提取图片 URL。每场比赛下载两张图（比分 + MVP），存入 result_images/SEASON/TEAM_vs_TEAM_ID/。每个赛季输出一个 CSV 到 csv_output/。

clip_label.py

OCR-based MVP identification. Crops the name-tag region from each mvp.png, runs Tesseract OCR, normalizes the text, and groups images with the same normalized name. Outputs a contact sheet PNG and a labels CSV for human review. After correction, --apply --confirm renames images to mvp_PLAYERNAME.png and writes MVP names into the season CSVs.

基于 OCR 的 MVP 识别。从每张 mvp.png 截取 name tag 区域，运行 Tesseract OCR，对文字 normalize 后分组。输出 contact sheet PNG 和标签 CSV 供人工校正。校正后运行 --apply --confirm 将图片改名为 mvp_PLAYERNAME.png，并将 MVP 名字写回赛季 CSV。

  └─ mvp.png  →  mvp_ACT_zz9.png

Key design decisions

主要设计决策

OCR over visual clustering

用 OCR 替代视觉聚类

Earlier versions used CLIP embeddings + KMeans. This caused same-team players (similar jerseys) to be merged. Since the name tag already contains the player name as text, OCR grouping is simpler and more accurate.

早期版本使用 CLIP embedding + KMeans，会把同队选手误分到同一组。由于 name tag 本身已包含文字，OCR 分组更简单也更准确。

Decoupled scraping and labeling

爬取与标注解耦

Separate scripts with no shared state. Re-label any year without re-scraping; scrape new years without disturbing existing labels.

独立脚本，无共享状态。可单独重新标注某年，也可爬取新数据而不影响已有标注。

Per-season CSV output

按赛季分文件输出

One CSV per season (e.g. 2025IVL_Autumn.csv) rather than a single combined file.

每个赛季单独一个 CSV（如 2025IVL_Autumn.csv），方便单独查看或更新。
